# علمِ تجوید

قرآنِ کریم کو مخارج و صفات کے ساتھ درست پڑھنے کا اردو ویب سائٹ (روایتِ حفص عن عاصم)۔

## مشمولات
- ۱۶ ابواب: تعارف، لحن، آداب، مخارج، صفات، تفخیم و ترقیق، نون/میم، مد، ادغام، ہمزہ، اجتماعِ ساکنین، وقف، رسم، قراءات
- حروف کا انٹرایکٹو مطالعہ، ۷۰ سے زائد سوالات کا امتحان، خلاصہ و جداول، فرہنگ
- المقدمۃ الجزریہ کے ۱۰۷ ابیات (حفظ کے لیے چھپانے کی سہولت کے ساتھ)
- تلاش، ڈارک موڈ، موبائل کے لیے موزوں

## مواد کی تصدیق
قواعد کو شاملہ پر موجود «قواعد التجوید» (القاری) اور جزریہ کے محقق متن سے ملا کر جانچا گیا ہے؛ تفصیل صفحۂ [مصادر](docs/sources.html) میں ہے۔ رسم اور قراءات کے ابواب تعارفی ہیں۔ خاکے صرف ان باتوں کو دکھاتے ہیں جو کتابوں میں صراحت سے مذکور ہیں۔

## چلانا
```bash
python3 build.py        # content/ سے docs/ بناتا ہے
python3 -m http.server -d docs 8000
```

## ڈھانچہ
- `content/` — ہر صفحہ ایک HTML ٹکڑا
- `template.html`, `assets/` — ڈھانچہ، انداز، اسکرپٹس
- `diagrams/`, `tools/` — SVG خاکے اور انہیں بنانے والی اسکرپٹس
- `docs/` — تیار سائٹ (GitHub Pages اسی سے چلتی ہے)

## GitHub Pages
Settings → Pages میں Source کو **GitHub Actions** رکھیں (یا branch `main` اور فولڈر `/docs`)۔
